# Ito ポートフォリオ

ポートフォリオサイトです。GitHub Pagesで公開できます。

## ファイル

- `index.html` — Webページの内容
- `index.css` — ページのデザイン
- `face.png` — ヘッダーに表示するプロフィールアイコン（70 × 70 px）

## GitHub Pagesで公開する

1. GitHubの `ito-hub0701.github.io` リポジトリを開きます。
2. 上記3ファイルとこの `README.md` をリポジトリのトップ階層にアップロードします。
3. 変更を `main` ブランチにコミットします。
4. **Settings → Pages** で、公開元が `main` ブランチの `/(root)` になっていることを確認します。
5. 数分後、[https://ito-hub0701.github.io/](https://ito-hub0701.github.io/) を開いて表示を確認します。

`face.png`はHTMLと同じフォルダーに置いてください。ファイル名の大文字・小文字も一致させます。
